# 📊 Amazon Sales Analysis Dashboard

## 📌 Project Overview

An interactive **Amazon Sales Analysis Dashboard** built using Microsoft Power BI to analyze sales performance, profitability, products, customers, discounts, shipments, and geographic performance.

The dashboard provides interactive filters and visualizations to help understand business performance and identify important sales and profit trends.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- Data Cleaning
- Data Modeling
- Data Visualization

---

## 📈 Dashboard Features

### KPI Analysis
- Total Sales
- Total Quantity
- Total Profit
- Total Shipment Cost

### Sales Analysis
- Sales by Product Category
- Sales Trend Over Time
- Sales by Customer Segment
- Sales by Sub-Category

### Profit Analysis
- Profit by Category
- Profit by Region
- State Profit Ranking
- Geographic Profit Distribution

### Other Analysis
- Average Discount by Sub-Category
- Regional Performance
- Interactive Slicers
- State-level analysis

---

## 🎛️ Interactive Filters

The dashboard includes filters for:

- Order Date
- Region
- State
- City
- Category
- Sub-Category
- Segment
- Ship Mode
